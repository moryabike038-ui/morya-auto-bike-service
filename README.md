# Morya Auto Bike Service Point — Website

A bilingual (English + Marathi), responsive React website built with Vite and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (typically http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Deploy

Upload the project to GitHub and import it into Vercel or Netlify. Build command: `npm run build`; output directory: `dist`.
